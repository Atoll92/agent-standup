What you see

Reading logs is work. Watching a call is not.

It reads the session files your agents already write and plays them as a meeting, live or as a replay of any past session.

Every agent has a desk

The lead gives orders. Sub-agents join the call when they get a task and leave when they are done. Whoever speaks gets the spotlight, with a voice and a moving mouth.

  • One status per agent: working, waiting on someone, needs you, done
  • Their reasoning shows up as small thought bubbles
  • Tokens per agent, and a context gauge before compaction

They share their screen

When an agent runs a command, you see the command and its real output. When it changes a file, you see the diff. Failed commands are marked, so the first error is easy to find.

Replay it, and get the recap

Pick any past session and scrub through it. Jump to the first error, the longest wait or a loop. At the end, a recap lists the agents, the commands, the errors, the tokens and the files that changed.

  • A tree of who asked whom
  • A board of every session, across projects
  • Export the call as a video

New

Codex and Mistral Vibe sessions too

Sessions of OpenAI’s Codex and of Mistral Vibe, Mistral’s coding agent, appear next to your Claude Code sessions: in the list, on the board and in the live call. So do the Cowork sessions of the Claude desktop app. Nothing to set up.

With Codex the call is the lead and you: its sub-agents are not shown yet. Mistral Vibe’s sub-agents do join the call.

The cast

Install

Use it where you work

One small local server, several ways in. You need to have used Claude Code, Codex or Mistral Vibe on this machine at least once.

VS Code

A panel and a side bar, plus live counts in the status bar that turn red when an agent may need you.

Open in the Marketplace

Then click the Agent Standup icon in the Activity Bar and press Join.

Cursor · Windsurf · VSCodium

The same extension, from Open VSX: search Agent Standup in the Extensions panel of your editor, then open it the same way.

Open VSXDownload the .vsix

Any terminal

No editor needed: it opens the call in your browser. Node 18 or later.

Desktop app

Its own window and a menu bar indicator, with a notification when an agent may need you.

macOS · Apple SiliconmacOS · IntelWindows · Linux

Not signed by Apple. The first time on a Mac: open it, close the warning, then System Settings → Privacy & Security → Open Anyway.

Inside Claude Code

A plugin with two commands: open the call, and a one-line status of who is working and who needs you. Node 18 or later.

On an older Claude Code, in two steps: /plugin marketplace add Atoll92/agent-standup/plugin install agent-standup@double-geste

Status bars

One short line for the Claude Code status line, tmux or anything else: how many agents are working, and whether one needs you.
