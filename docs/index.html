Agent Standup turns your Claude Code or Codex session into a live team meeting: the lead gives orders, sub-agents join, share their screen and report back. It’s a bit silly. It’s also weirdly useful.

(An illustration. The real thing is live, has voices, and follows your actual session.)

It works wherever you run Claude Code or Codex.
